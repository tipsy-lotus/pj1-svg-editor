# ADR 005：box 子部件与读回策略

box 插件提供图形、属性处理器与类型标签三个贡献。内部必要部件固定为直接子节点 `<id>-rect`（Rect）和 `<id>-label`（Text），构造时必须同时存在且各一个。标题初始位置为 x+20、y+h/2+5；框体默认填充 #4a90d9，标题白色。CLI 数值与原有图形采用相同校验。

图形保存为带 data-kind="box" 的普通 g，保留额外属性与子树。专用提供器优先级为 100；未装插件时由默认 g 提供器读回，保留结构但没有 box 的属性和保护语义。已装插件时，对缺少必要部件、类型错误或非空容器文本选择拒绝整个读入，不生成残缺对象。重复 id 由内核预先全局检查并拒绝，不能以降级掩盖。

普通删除、移出、收编必要部件均拒绝；front/back 因使用移除再插入，也采取严格拒绝策略。box 自身不能解组，但可整体删除、移动、缩放、收编和嵌套。clone 保留 Box 类型，确保撤销后结构保护仍然生效。

fill 和 label 由独立 BoxAttributes 处理，分别调用 Box 的公开方法修改内部矩形或标题，不给普通图形增加 label 白名单。属性冲突和失败回滚沿用 ADR 002；树行通过 BoxTypeDecorator 追加 (box)，不读取或依赖其他标签实例。

当前配置接入提交以已合并的命令插件版本 f544a0c 为父版本，仅新增 box 包与测试并修改配置/文档，内核和既有插件差异为空。独立运行测试验证两种装配行为一致；代码装配方式的新增插件提交差异和完整 §6.1 会话证据仍待补充，不能以单元测试代替这两项。
